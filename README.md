# Cratebox

DJ software for the Pioneer DDJ-FLX4 and friends, in one repo:

- [`apps/web/`](apps/web/): the browser player (`cratebox.html`) and the website.
- [`apps/linux/`](apps/linux/): Cratebox OS (Linux kiosk) and Cratebox for Windows, in Rust.
- [`apps/ios-suite/`](apps/ios-suite/): the native iOS app (Performance Mode, Deck Bridge, Cratebox USB).

Each app has its own README. For contributors and AI agents: start at [AGENTS.md](AGENTS.md) (index: [LLMS.txt](LLMS.txt)).

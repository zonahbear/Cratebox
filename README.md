# Cratebox

DJ software for the Pioneer DDJ-FLX4 and friends, in one repo:

- [`web/`](web/): the browser player (`cratebox.html`) and the website.
- [`linux/`](linux/): Cratebox OS (Linux kiosk) and Cratebox for Windows, in Rust.
- [`ios-suite/`](ios-suite/): the native iOS app (Performance Mode, Deck Bridge, Cratebox USB).

Each folder has its own README. Map for contributors and agents: [CLAUDE.md](CLAUDE.md).
